# Images du site

Dépose tes photos dans ce dossier (`public/images/`).

Tu peux garder n'importe quels noms de fichiers : je regarderai chaque image et
je l'affecterai au bon endroit, puis je te montrerai le plan avant de publier.

Si tu préfères nommer toi-même, voici les emplacements du site et le nom de
fichier attendu pour chacun :

| Fichier suggéré        | Où il apparaît sur le site                                  | Format conseillé |
|------------------------|-------------------------------------------------------------|------------------|
| `hero.jpg`             | Photo principale de la page d'accueil (héros)               | portrait 4:5     |
| `about.jpg`            | Portrait de la page « À propos » (+ aperçu accueil)         | portrait 4:5     |
| `teaching.jpg`         | Section « La méthode » (accueil) + bandeau « À propos »     | paysage 4:3      |
| `homeopathie.jpg`      | Page Homéopathie + carte discipline « Homéopathie »         | portrait 4:5     |
| `sujok.jpg`            | Page Sujok + carte discipline « Sujok »                     | portrait 4:5     |
| `ville-casablanca.jpg` | Carte de formation à Casablanca                             | paysage 16:10    |
| `ville-rabat.jpg`      | Carte de formation à Rabat                                  | paysage 16:10    |
| `ville-marrakech.jpg`  | Carte de formation à Marrakech                              | paysage 16:10    |
| `ville-autre.jpg`      | Carte de formation (autres villes, par défaut)             | paysage 16:10    |
| `galerie-1.jpg` … `-5` | Grille « Formations en images » (accueil)                   | mixte            |

## Conseils techniques
- **Format** : JPG ou WebP.
- **Résolution** : ~1200–1600 px de large suffit largement.
- **Poids** : vise < 400 Ko par image pour un site rapide (je peux optimiser si besoin).
